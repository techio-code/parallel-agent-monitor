Claude Codeの出力を貼り付けて自動でタスク追加
使い方：Claude Codeのターミナルに表示されたログをそのままコピーして、下のテキストエリアに貼り付けるだけです。 AIが「agentId」「completed」「error」などのキーワードを自動で読み取り、タスクカードを作成・更新します。

こんなテキストが自動で読み取れます（例）：
Async agent launched successfully. agentId: a72b8de9 name: investor Task started: engineer — refactoring auth module Agent a72b8de9 completed successfully
